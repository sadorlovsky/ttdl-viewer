---

Нужен [Bun](https://bun.sh) 1.4+.

```bash
bun install
bun run dev
```

Интерфейс на <http://127.0.0.1:4173>, API на `:4174`.

## Когда архивов на диске ещё нет

Сгенерируйте синтетический, чтобы осмотреться — нужен `ffmpeg` (`brew install ffmpeg`):

```bash
bun run fixtures
```

Он пишет `fixtures/downloads/`: архив профиля, список с многими авторами, пустой архив, каталог
посторонних файлов и экспорт данных TikTok. Что внутри сломано намеренно и почему — см.
[Фикстуры и проверки](/ru/reference/fixtures-and-checks/).

## Одним процессом, как в продакшене

```bash
bun run build
bun run start        # всё на :4174
```

`bun run build` запускает сборку Vite, а затем офлайн-проверку по `dist/`; сборка падает на любой
удалённой ссылке в бандле.

## Как навести его на ваши архивы

`--root` — единственное, что он не может выяснить сам, и спрашивается это один раз:

```bash
bun run start --root ~/code/ttdl/downloads   # запомнится на следующий раз
bun run start                                # и больше не понадобится
```

Всё остальное про это — где он запоминается, что пробуется, если не дать ничего, и почему угаданный
корень намеренно не сохраняется — в [Настройке](/ru/start/configuration/).
